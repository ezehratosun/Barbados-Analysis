# Environmental Kuznets Curve (EKC) Analysis

## Project Overview
This project examines the relationship between economic development and CO2 emissions per capita using the Environmental Kuznets Curve (EKC) hypothesis.

## Country and Period
- Country: Barbados
- Period: 1970–2024
- Data source: World Bank – World Development Indicators

## Variables
- CO2 emissions per capita (excluding LULUCF)
- GDP per capita (constant US$)

## Methodology
1. Downloaded annual data from the World Bank.
2. Calculated the natural logarithm of both variables.
3. Created a scatter plot with a linear regression line.
4. Estimated a quadratic OLS regression model.
5. Interpreted the regression results to evaluate the EKC hypothesis.

## Files
- Data/: Raw and logged datasets.
- Code/: R script used for the empirical analysis.
